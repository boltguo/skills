# Audit report template

Use only in `audit` mode. Do not infer authorship and do not report an AI percentage.

```markdown
## Overall assessment

[Two to four sentences: genre, dominant issue, what is already working, and the safest editing scope.]

## Findings

| # | Location / excerpt | Category | Confidence | Severity | Why it hurts this piece | Suggested operation |
|---|---|---|---|---|---|---|
| 1 | “...” | structure / vague source / translationese / ... | high / medium | major / moderate / minor | [context-specific effect] | keep / delete / compress / specify / re-attribute / merge / split / reorder / verify |

## Protected material

- [Numbers, terms, quotations, commands, warnings, or relationships that must not change]

## Recommended editing scope

[strict / standard / creative, with one-sentence reason]

## Unresolved questions

- [Only accuracy gaps that block a safe revision]
```

Report the most material 3–8 findings by default. An exact excerpt is required for every finding. A phrase list without context is not an audit.
