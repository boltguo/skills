# Fidelity ledger template

Keep this internal unless the user asks to see it.

```markdown
| Item | Type | Source form | Required relation | Result check |
|---|---|---|---|---|
| [name / number / term / condition] | literal / semantic / structural | [exact source] | [what must remain true] | pass / fail / unresolved |
```

Suggested rows:

- names and responsibility
- numbers, units, baselines, dates, and ranges
- negation, scope, modality, and exceptions
- chronology and completion state
- causality and comparison direction
- quotations and attribution
- code, commands, paths, fields, and URLs
- warnings, prerequisites, and fixed formal wording
